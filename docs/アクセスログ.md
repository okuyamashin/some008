# アクセスログ

gamebook.engawa5656.com のアクセスログです。仕組みは some005（colorsofthefool）と同じです。

CloudFront の標準ログ記録 (v2) が、アクセスのたびに JSON を S3 へ出します。Lambda `gamebook-access-csv` が、それを日本時間の1日ごとに1つの CSV へまとめます。コードは `lambda/access_log_csv/handler.py` です（some005 と同じコードで、ディストリビューションの既定値だけが違います）。

ディストリビューションは `E1P47C37OV1I3G`、Lambda とスケジュールのリージョンは `ap-northeast-1` です。ログ配信の設定（配信元 `gamebook-access`、配信先 `gamebook-access-s3`）は `us-east-1` にあります。レガシーのログ配信はオフです。いちばん古いログは、協定世界時の 2026-10-16 13:00（日本時間の 2026-10-16 22:00）です。

## 元のログ

バケット `s3://gamebook-logs-engawa5656` の `AWSLogs/868118155022/CloudFront/` に、gzip した JSON が1行1アクセスで届きます。ファイル名は `E1P47C37OV1I3G.年-月-日-時.識別子.gz` で、この日時はリクエストのあった協定世界時の時です。

CloudFront は、リクエストからおおよそ1時間以内にファイルを置きます。遅れて届くことがあり、その場合もファイル名の時刻はリクエストの時です。

バケットは非公開で、ライフサイクルの設定により、元のログも CSV も90日で消えます。

## CSV

同じバケットの `csv/年-月-日.csv` です。例は `csv/2026-10-17.csv`。文字コードは UTF-8、1行目が列名、区切りはカンマです。同じ日付のファイルは、追記せずにその日の分を書き直します。

ファイル名の日付は日本時間です。中の `date` と `time` は、元のログと同じ協定世界時です。行は `date`、`time`、`x-edge-request-id` の順に並びます。

過去の日は、その日の 0:00 から翌日の 0:00 の直前までを書きます。当日は、実行時刻の1時間前より前までです。未来の日付を渡すと失敗します。

日付を渡さない実行は、前日の全体を書きます。予定 `gamebook-access-csv`（EventBridge Scheduler）は、日本時間の毎日 0:01 にこの呼び出しをします。

ある日だけ出すときは、日付を渡します。

```sh
aws lambda invoke \
  --function-name gamebook-access-csv \
  --region ap-northeast-1 \
  --cli-binary-format raw-in-base64-out \
  --cli-read-timeout 300 \
  --payload '{"date": "2026-10-17"}' \
  /tmp/gamebook-access-csv.json
```

戻り値の `rows` がその日の行数、`until` が含めた範囲の終わり（この時刻は含まない）です。

CSV を手元に取ってくるときは次のとおりです。

```sh
aws s3 cp s3://gamebook-logs-engawa5656/csv/2026-10-17.csv .
```

## Lambda を更新するとき

`lambda/access_log_csv/handler.py` を書き換えたら、zip にして上げ直します。

```sh
cd lambda/access_log_csv && zip -q /tmp/gamebook-access-csv.zip handler.py && cd -
aws lambda update-function-code --function-name gamebook-access-csv --region ap-northeast-1 \
  --zip-file fileb:///tmp/gamebook-access-csv.zip
```

## AWS のリソース

| 種類 | 名前 | 内容 |
| --- | --- | --- |
| S3 バケット | gamebook-logs-engawa5656 | 元のログと CSV。非公開、90日で削除 |
| ログ配信元（us-east-1） | gamebook-access | ディストリビューション E1P47C37OV1I3G の ACCESS_LOGS |
| ログ配信先（us-east-1） | gamebook-access-s3 | 上のバケットへ JSON で |
| Lambda | gamebook-access-csv | Python 3.12、300秒、512MB |
| IAM ロール | gamebook-access-csv | Lambda 用。ログの読み取りと csv/ への書き込みだけ |
| IAM ロール | gamebook-access-csv-schedule | スケジュール用。上の Lambda の呼び出しだけ |
| スケジュール | gamebook-access-csv | 毎日 0:01（Asia/Tokyo） |
